1. ОБЗОР ПРОЕКТА
Это одинокая страница…
Тихая, тёплая и немного странная, как подземелье, полное души.
Статический сайт для GitHub Pages в стиле Undertale — с ретро-пиксельным шармом, жёлтым сердцем и атмосферой, которая одновременно милая и чуть грустная.
Тёмный фон, жёлтые акценты, лёгкие снежинки/звёздочки, которые медленно плывут вниз, как в Руинах или в Снежном лесу. Всё очень атмосферно, без лишней мишуры.
Основные цвета темы
#1F201F · #C0963D · #9A5602 · #54423A · #C3BFB8 · #96795F
Текст — высокий контраст, как белые буквы на чёрном фоне в Undertale.
содержит плавающие смайлики 🙃🌚

2. КЛЮЧЕВЫЕ ТРЕБОВАНИЯ
Визуальный стиль

Тёмный фон с лёгким градиентом
Пиксельный/ретро шрифт в заголовках
Плавающие жёлтые сердечки и маленькие звёздочки, медленно двигающиеся по экрану
Центральная «карточка» с мягким свечением, как будто это душа
Большая область для фото друга
Полностью адаптивно (отлично выглядит и на телефоне, и на компьютере)

Структура контента

Большой заголовок с именем и возрастом друга
Большая область для твоего личного поздравительного текста
Секция с одним треком (в стиле Undertale)
Нижний колонтитул с подписью отправителя

Музыка
Только одна композиция.
Встроенный минималистичный плеер в стиле Undertale (без автозапуска).
Пользователь должен сам нажать «Play».
Музыка продолжает играть при взаимодействии со страницей.

4. ФУНКЦИОНАЛЬНЫЕ ХАРАКТЕРИСТИКИ
При загрузке страницы

Тёмный экран
Медленно плывут жёлтые сердечки и звёздочки
Появляется центральная карточка
Плеер готов, но молчит (как надо в Undertale)

Взаимодействия

Всё дружелюбно к пальцам (сенсорное управление)
Плеер: Play / Pause + название трека
Никаких лишних кнопок

Технические требования

Только HTML + CSS + JavaScript (без библиотек)
Быстрая загрузка даже на мобильном интернете
Работает во всех современных браузерах
Работает без JavaScript (базовый вид остаётся читаемым)
